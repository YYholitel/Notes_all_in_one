## 布尔代数 

### one variable 
 - Identity ： x + 0 = x ; x·1 = x (dual form)
 - Null Element : x +1 = 1 ; x · 0 =  0 
 - Idempotency (幂等) : x +x = x  ; x · x  =x 
 - Involution  : (x')' = x 
 - Complements : x+ x’ = 1 ； x ·x'  =  0 

### precedence 
Parentheses > NOT>AND>OR
### multiple Variables 
- commutativity  :xy = yx ; x+y =y+x 
- Associativity : (xy)z = x(yz)
- Distributitvity: x(y+z) = xy + xz  ;  x+yz = (x+y)(x+z)
- Absorption : x + xy = x ;  x(x+y) =x  ; 
- Combing xy +xy'  =x 
- Simplification : (x+y')y = xy ;  xy' + y  = x + y 
- Consensus  : xy+x'z +yz = xy + x'z
- DeMorgan's Law  ： (x+y) '   =x'y'  ; (xy)' = x' + y '  ( 否定的同时改变运算关系 )
- XOR ： Axor B = AB' + A'B

## minterm and maxterm 
- minterm :  包含所有的输入的变量的 AND 
	-  对于输入变量 ： x, y  , x'y就是一个最小项 
- maxterm 最大项： 包含所有输入变量的 OR  ，  且 **输入形式相反 **  
	-   对于输入变量 x, y  ; x + y  '  就是一个最大项
