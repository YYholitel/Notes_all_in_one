# 线性无关 
	
设 V是数域 $\mathbb{F}$ 上 的 一个 向量空间 ， 存在一组数量 $v_{1,}v_{2},\dots,v_{n}$ $\in V$
$c_{1},c_{2},\dots,^{3}\in \mathbb{F}$
且 
$$
c_{1}v_{1} +c_{2} v_{2} +\dots + c_{n}v_{n} = 0;

$$
只有$$ c_{1} = c_{2} =\dots =c_{n} = 0 $$
那么这组向量称为 线性无关

# 四大空间 

## column  space 
对于矩阵A ， 所有的 列向量的 线性组合的集合 就是 列向量
也叫做满足 $Ax=b$的b的集合
对于 一个线性的 映射， x $|\to$ Ax ， 列空间就是 Image
列空间的 维度 为 ： Rm
维度为 rank(A) （列秩=行秩）

### 求解方法：
高斯消元  + 主元列的 **原** 列向量  ，因为消元过程 相当于 TA的线性变换 


## row  space 
$$
C(A^T)
$$
 对于矩阵A ，所有的 行向量的 线性组合 的集合 
 含义： 等同于 $A^T$   的列空间 
 维度 $\mathbb{R}^n$
### 求解方法： 
row echlon form + 取所有的 非0行 

## Null Space 
$$
N(A)
$$
 满足Ax = 0 的 向量x的集合
 也就是 被A映射后 成为 0 向量的 输入集合 Kernel
维度 ： 0  行和 左 0 列分别一个维度 

### 求解方法 ：
解方程 Ax= 0 ;
	- [ ] 令自由变量轮流为 0即可（就是 描述每个自由的方向 上 的 贡献 ）  

## Left Null Space
