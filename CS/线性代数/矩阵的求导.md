# 📔 矩阵求导恒等式：分母布局精要

> 核心原则：结果的维度必须与分母（求导变量）的维度保持一致。
> 
> 布局规范：分母布局 (Denominator Layout)，即标量对向量求导结果为==列向量。
	
	---
	
	## 1. 线性与二次型算子 (Fundamental Forms)
	
	### (1) 线性内积梯度
	
	公式：

$$\frac{\partial(\mathbf{x}^\top\mathbf{a})}{\partial \mathbf{x}} = \frac{\partial(\mathbf{a}^\top\mathbf{x})}{\partial \mathbf{x}} = \mathbf{a}$$

- **理解记忆**：这是标量求导 $(ax)' = a$ 的高维==平移。
    
- **直觉**：内积就是投影。当你沿着 $\mathbf{x}$ 的分量去“拉扯”函数时，增长最快的方向自然就是 $\mathbf{a}$ 向量本身的方向。
    

### (2) 向量模长平方（自内积）

公式：

$$\frac{\partial(\mathbf{x}^\top\mathbf{x})}{\partial \mathbf{x}} = 2\mathbf{x}$$

- **理解记忆**：==类比标量求导 $(x^2)' = 2x$。
    
- **直觉**：$\mathbf{x}^\top\mathbf{x}$ 是到原点距离的平方。向外走时，距离增加的速度与当前位置 $\mathbf{x}$ 成正比。
    

### (3) 二次型公式 (The Quadratic Form)

公式：

$$\frac{\partial(\mathbf{x}^\top\mathbf{A}\mathbf{x})}{\partial \mathbf{x}} = (\mathbf{A}+\mathbf{A}^\top)\mathbf{x}$$

- **理解记忆**：类比 $(ax^2)' = 2ax$。如果 $\mathbf{A}$ 是对称矩阵（即 $\mathbf{A}=\mathbf{A}^\top$），则公式变为 $2\mathbf{Ax}$。
    
- **直觉**：这是描述曲面曲率的核心。$\mathbf{A}$ 决定了曲面的“碗口”向哪边开。

## 2. 矩阵“夹心”求导 (The Sandwich Rule)

这是处理线性回归最常用的公式。

### (4) 矩阵外夹转置版

公式：

$$\frac{\partial(\mathbf{a}^\top\mathbf{X}\mathbf{b})}{\partial \mathbf{X}} = \mathbf{a}\mathbf{b}^\top$$

- **理解记忆**：**“头尾相乘，顺序不变，中间改转置”**。
    
- **维度自检**：左边 $\mathbf{a}$ 是 $m \times 1$，右边 $\mathbf{b}^\top$ 是 $1 \times n$，结果是 $m \times n$，正好对齐 $\mathbf{X}$ 的形状。
    

### (5) 矩阵转置外夹版

公式：

$$\frac{\partial(\mathbf{a}^\top\mathbf{X}^\top\mathbf{b})}{\partial \mathbf{X}} = \mathbf{b}\mathbf{a}^\top$$

- **理解记忆**：公式 (4) 的==整体转置==。此时 $\mathbf{b}$ 在前，$\mathbf{a}$ 在后。
    
- **直觉**：$\mathbf{X}$ 变转置了，梯度的贡献方向也会随之“翻转”。

## 3. 双向量矩阵乘积 (Matrix-Vector Compositions)

### (6) 矩阵外积平方公式

公式：

$$\frac{\partial(\mathbf{a}^\top\mathbf{X}\mathbf{X}^\top\mathbf{b})}{\partial \mathbf{X}} = (\mathbf{a}\mathbf{b}^\top + \mathbf{b}\mathbf{a}^\top)\mathbf{X}$$

- **理解记忆**：类比 $(x^2)'$。保留一个 $\mathbf{X}$，剩下的常数向量组成对称矩阵 $(\mathbf{ab}^\top + \mathbf{ba}^\top)$ 放在前面。
    

### (7) 整体内积公式（最小二乘法原形）

公式：

$$\frac{\partial(\mathbf{a}^\top\mathbf{X}^\top\mathbf{X}\mathbf{b})}{\partial \mathbf{X}} = \mathbf{X}(\mathbf{b}\mathbf{a}^\top + \mathbf{a}\mathbf{b}^\top)$$

- **理解记忆**：这是公式 (6) 的==镜像==。**注意 $\mathbf{X}$ 的位置**：如果 $\mathbf{X}$ 在公式里带转置在前，导数里 $\mathbf{X}$ 就在后；反之亦然。
    
- **学术注记**：这直接决定了你代码里 `gradients` 的 `dot` 顺序。

- **口诀**：==右不变，右往左==
- **使用量纲分析！**：==维度不变==

#### (9).逐元素运算 (Element-wise)

**公式**：$\frac{\partial \sigma(\mathbf{x})}{\partial \mathbf{x}} = \text{diag}(\sigma'(\mathbf{x}))$

- **理解**：如果每个 $y_i$ 只由 $x_i$ 决定，那么梯度矩阵只有对角线有值。
